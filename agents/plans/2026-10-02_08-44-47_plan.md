# Passkey login plan

## Specification

- Add WebAuthn passkeys as an optional sign-in method for existing accounts.
- Allow a signed-in user to register and remove their own passkeys, except during impersonation.
- Bind each registration and login ceremony to a one-time, short-lived D1 challenge and an HTTP-only browser cookie. Verify the RP ID, origin, and user verification on the server.
- Use the existing session flow after a successful assertion. Keep email-link sign-in and safe `next` redirects.
- Store credential public keys and counters in D1. Add a new migration; do not alter existing migrations.
