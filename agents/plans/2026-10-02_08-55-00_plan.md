# Magic-link passkey setup plan

## Specification

- Offer passkey setup on a valid email-link landing page when the linked account has no passkey.
- Both buttons must consume the email token once and create the normal session before any passkey registration.
- The setup choice redirects to the authenticated passkey page. The regular choice preserves the existing safe return path.
- Do not create an account or consume the token during the GET that renders the landing page.
