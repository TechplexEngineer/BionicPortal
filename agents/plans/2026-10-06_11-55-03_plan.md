# SOPs admin navigation

## Design

The SOPs route sits outside `/admin` so mentors can read it. The admin layout owns the admin dashboard tab list, while the SOPs page has no dashboard header. Move that list into a shared module and render the existing `DashHeader` above SOP content. Admins get the admin tabs; mentors get Dashboard and SOPs tabs. Keep SOP permissions and editing behavior unchanged.
