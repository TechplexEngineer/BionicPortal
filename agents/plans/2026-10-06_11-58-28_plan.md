# Show form counts on event cards

## Design

The Events Management page should tell an admin how many saved forms each event has. Every event card will have a Forms link labeled with its count, including zero, leading to that event's forms management page. Counts come from `event_forms.event_id`; the older `permissionFormUrl` field does not represent forms added through the forms page. Use one query for all form rows and Bootstrap button styling already used by the card.
