# Move form deletion into the editor

## Design

The event forms list offers View and Edit for each form, without a Delete control or inline confirmation. The form editor offers Delete form beside Back to forms. Clicking it opens a server-rendered confirmation on that editor URL; confirming posts to the existing event forms delete action so its submission guard, R2 cleanup, and success or warning feedback remain in one place. Cancel returns to the editor.
