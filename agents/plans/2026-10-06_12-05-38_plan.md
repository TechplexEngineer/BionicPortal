# Standalone Forms Implementation Plan

## Goal and design

Add Bionic Sign forms independent of events. Admins upload and design a PDF form, assign it to selected students, and see assignment progress. A student sees every assigned form and submits their portion. A linked parent completes required `parent_` fields for a minor. Incomplete assignments appear in student action items; parent work appears in the parent dashboard.

Use dedicated `standalone_forms` and `standalone_form_assignments` tables rather than synthetic event registrations. Store the base PDF and final flattened PDF in the existing R2 forms bucket; store validated field values and submission state in D1. Assignment is the access boundary. `studentSubmittedAt` records a deliberate student submission, distinct from a draft or fields that happen to be complete. A form is submitted only after the student's submission and any required parent fields for a minor are complete. Age is evaluated on the current date. Parents must have an existing parent-student link to complete their portion. This reuses the existing parent dashboard authorization model without email invitations.
