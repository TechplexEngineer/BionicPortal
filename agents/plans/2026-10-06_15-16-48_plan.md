# Delete mistaken event permission forms

## Design

Admin users can delete an unused saved form from the event forms list. The row opens an inline confirmation that works without JavaScript. The server scopes the requested form to the event in the route and rejects deletion when any submission exists, preserving signed records. For an unused form, it deletes the database row and its blank PDF from R2. Stored registration completion is preserved because it can be set manually; after deleting the last form, admins receive a reminder to review those statuses. A failed R2 cleanup is logged with its object key and shown as a warning.
