## Review

- Root cause: the admin edit action treated an unchecked approval checkbox as `mentorApproved: false` even when changing a normal user into a mentor, so the secure layout redirected that user from Events and dashboard routes to mentor registration.
- Fix: detect a non-mentor-to-mentor promotion and approve it by default; existing mentor accounts still require the approval checkbox to leave pending status.
- Regression coverage: the new promotion test failed before the fix and passes after it; the pending-mentor test protects the approval workflow.
- Verification: all unit tests pass (48 files, 199 tests); production build passes; changed files pass ESLint, Prettier, and `git diff --check`.
- Existing repository issues: `npm run check` still reports the pre-existing `Record` type error in `src/routes/(secure)/admin/users/+page.svelte` plus warnings; `npm run lint` reports unrelated formatting failures in 38 existing files. Playwright could not start because the sandbox blocks Wrangler's local listener and log path.
