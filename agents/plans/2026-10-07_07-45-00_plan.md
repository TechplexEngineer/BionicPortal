# Form Assignment Mode Plan

## Goal

Replace per-student standalone form assignment with a form-level Draft/Assigned state. An Assigned form is required for every visible student. The existing per-student rows remain completion records so student and parent values stay isolated and progress can be reported.

## Design

- Add `standalone_forms.status` with `draft` and `assigned` values; add a forward migration.
- Replace the admin student picker and assign/unassign actions with an Assign to all students / Return to draft transition. Assigning creates completion rows for current visible students; student dashboard discovery creates a row for any later visible student.
- Keep `/admin/forms/[formId]/assignments` as a progress page, showing every visible student and their completion state without individual assignment controls.
- Student dashboard loads assigned forms and completion rows, including newly assigned forms; Action Items continues to show all forms and status badges.
- Preserve existing Bionic Sign, parent completion, frozen parent requirement, and assignment authorization behavior.

## Verification

- Test draft/assigned transitions, all-student row creation, duplicate-safe discovery, and progress states.
- Run focused tests, `npm run check`, full unit tests, and production build.
