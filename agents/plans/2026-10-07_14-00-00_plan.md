# Student Form Uploads Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Let students submit a completed PDF or scanned image as an interim final form artifact.

**Architecture:** Reuse the existing event and standalone submission rows and R2 forms bucket. A shared server helper validates a single uploaded file, stores it with a form-scoped key, and returns the key/content type. Uploaded files bypass the parent-signature step while existing interactive signing remains available.

**Tech Stack:** SvelteKit, Svelte 5, TypeScript, Vitest, Cloudflare R2, Drizzle ORM, Bootstrap utilities.

## Decisions

- Accepted types: `application/pdf`, `image/jpeg`, `image/png`, `image/webp`.
- Maximum size: 10 MiB.
- Uploads are treated as final interim submissions and do not require parent completion.
- Stored objects use assignment-scoped keys and preserve the uploaded content type.
