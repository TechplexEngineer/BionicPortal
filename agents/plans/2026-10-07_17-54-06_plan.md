# Apply Student Overview Filter to Attendance Plan

**Goal:** Make student attendance use the same current-versus-archived student filter as the student overview page.

**Architecture:** Parse `showArchived=true` in the attendance page loader and reuse the overview’s hidden/last-year predicate when loading students. Expose the state to the Svelte page and render matching Bootstrap links in the table toolbar.

**Tech Stack:** SvelteKit, Svelte 5, Drizzle ORM, Vitest, Bootstrap utility classes.
